# 小程序页面与逻辑检查记录

本记录为代码检查与自动化行为验证结果。本次未取得微信开发者工具或真机截图，不代表已完成平台视觉验收。

| --- | --- |

| 商品目录 `pages/catalog/index` | 旧请求不覆盖新筛选；加载更多失败不跳过页码；双列网格可收缩、长商品名两行省略、标签换行。 |
| 商品详情 `pages/catalog/detail` | 检查散珠/套餐分支与 DIY 参数；长说明、配方名称换行；底栏预留安全区。 |
| DIY 编辑 `pages/diy/editor` | 修复历史快照覆盖实时价格、硬编码绳材选择、筛选请求丢失、旧报价覆盖已修改设计、保存与下单双重保存；保存期间冻结实际设计，执行最大珠数限制；可恢复错误保留编辑器，初次加载失败单独呈现；搜索/配置项可收缩，底栏留安全区。 |
| DIY 方案 `pages/diy/schemes` | 检查恢复、最低金额、删除、数量限制及预览待补状态；顶部操作可换行，长方案名不挤压状态，摘要可换行。 |
| 确认订单 `pages/order/confirm` | 防止加载前/重复提交；优惠券门槛保留小数；按钮改为“提交订单”匹配实际动作；地址/名称/价格布局、优惠券弹层滚动与安全区修正。 |
| 订单列表 `pages/order/list` | 检查刷新、状态映射、详情入口；订单信息与联系方式可收缩/换行，状态和详情入口保留宽度。 |
| 订单详情 `pages/order/detail` | 防止并发订单操作；展示真实物流公司/运单号，缺失时显示等待提示；复制有效单号及失败反馈；制作清单长名称与底部安全区修正。 |

跨页处理：原有 `strong` / `i` 写法统一为原生 `text` 与样式类，保留原有强调/标签样式；request、upload、访客会话遇到 null 响应体时走可捕获的错误处理，避免直接访问 `code` 抛出异常。

行为修改均先加入失败测试，观察预期失败后修复。布局修改未添加仅检查样式文本的镜像测试。测试覆盖目录竞态与失败翻页、DIY 价格恢复/筛选/旧报价/保存互斥/保存期间编辑/珠数限制/绳材配置、订单/资料/地址防重、金额精度、空响应及物流复制。

最终验证：27 个测试套件、222 条测试全部通过；TypeScript 类型检查通过；diff 空白检查通过。
