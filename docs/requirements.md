# 需求规格说明

最后更新：2026-07-10

## 1. 产品目标

交付一个真实可操作的 DIY 手串商品系统，由 Spring Boot 后端、Vue 3 管理后台和原生微信小程序组成。当前版本目标是形成“商品维护 → 小程序浏览 → DIY 排珠 → 权威报价 → 保存方案 → 恢复方案”的可用产品闭环。

当前阶段不接入真实支付、微信授权和对象存储；本地文件存储、访客身份和后续第三方能力均保留替换边界。

## 2. 用户角色

- 访客/顾客：浏览商品、进入 DIY 工作台、调整腕围/松紧/绳材、增删改排珠、确认报价、保存/复制/删除方案。
- 管理员：维护商品目录、素材、DIY 规则、工艺费区间和绳材选项。
- 系统：校验 SKU 状态、尺寸规则、最大珠数、绳材和工艺费，生成权威报价和方案快照。

## 3. 已实现功能范围

### 3.1 商品目录

- 管理分类、散珠 SKU、套餐、有序套餐明细和封面。
- 公共目录仅返回已上架数据，不暴露成本价。
- 支持关键字、分类、状态和分页查询。
- 商品图片限制为 PNG、JPEG、WebP，默认最大 5 MiB。
- 套餐明细按 SKU 与数量保存，进入 DIY 时前端临时展开为有序序列。

### 3.2 DIY 设计与计价

- 小程序支持从空白、单颗 SKU、套餐和已保存方案进入编辑器。
- 设计状态只保存有序 SKU 数组，不为每颗珠子创建业务 ID。
- 前端支持添加、删除、替换、拖动排序、同 SKU 数量增减、撤销和重做。
- 本地根据已加载商品、工艺费和绳材做预估价；最终权威报价只由后端读取服务端 SKU 与配置计算。
- 后端校验下架/不存在 SKU、最大珠数、腕围范围、尺寸偏差和绳材可用性。
- 尺寸不合适时允许保存草稿，但不可生成可用权威报价。

### 3.3 方案保存与预览

- 访客通过安装 UUID 换取顾客 JWT，不依赖微信授权。
- 方案支持新建、读取、更新、复制、软删除和列表查询。
- 方案更新使用乐观锁，旧版本更新返回 409。
- 方案保存 SKU 顺序数组和报价快照；读取时重新评估当前报价状态。
- 小程序保存后导出 Canvas 预览并上传；预览上传失败不会回滚方案，只记录待重试提示。
- 两个访客之间不能访问对方方案。

### 3.4 管理后台 DIY 配置

- 管理后台可调整腕围范围、松紧余量、尺寸容差、最大珠数。
- 可维护工艺费区间，页面阻止重叠区间提交。
- 可维护绳材名称、颜色、附加费和启用状态。
- 配置通过后端持久化，小程序和计价服务读取同一份配置。

## 4. 尚未实现范围

- 未接微信授权；当前使用本地安装 UUID + 顾客 JWT。
- 未接真实对象存储；当前使用本地 `FileStorage`。
- 未实现推荐、库存、订单、模拟支付和履约。
- 小程序访客方案只能在同一安装身份下访问，换设备/清缓存后无法自动找回。
- 未接微信支付；当前版本不能完成真实交易收款。

## 5. 非功能需求

- JDK 17、Spring Boot 3.3、MySQL 8、Vue 3、原生微信小程序。
- 金额使用 `decimal`/`BigDecimal`，前端金额显示不作为最终报价权威。
- 数据库结构只通过 Flyway 演进。
- 管理接口使用管理员 JWT；小程序方案接口使用顾客 JWT。
- 统一响应含 `code`、`message`、`data`、`traceId`、`timestamp`。
- 关键流程提供 JUnit/Testcontainers、Vitest/Jest 和 TypeScript 类型检查。
- Java 公共类型和关键规则使用中文 Javadoc；TypeScript 公共逻辑说明状态和边界。

## 6. 阶段验收

### 当前 DIY 纵向链路

- 管理后台可维护商品和 DIY 规则。
- 小程序可从商品/套餐进入 DIY，调整顺序并保存方案。
- 后端权威报价使用服务端配置和 SKU 数据。
- 方案保存和读取保持 SKU 顺序完全一致。
- 访客 token 与管理员 token 不能互换。
- 预览上传失败不丢失方案。
- `scripts/catalog-smoke.sh` 和 `scripts/diy-smoke.sh` 用于真实 HTTP 冒烟。

### 完整 V1

在当前能力外，还必须完成推荐、库存、订单、模拟支付和履约闭环，才可标记为“完整 V1”。
