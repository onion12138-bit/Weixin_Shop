# 需求规格说明

最后更新：2026-07-11

## 1. 产品目标

交付一个真实可操作的 DIY 手串商品系统，由 Spring Boot 后端、Vue 3 管理后台和原生微信小程序组成。当前版本已形成“商品维护 → 小程序浏览 → DIY 排珠 → 权威报价 → 保存方案 → 库存预占 → 创建订单 → 模拟支付 → 制作发货”的本地可用产品闭环。

当前阶段不接入真实微信支付、微信授权和对象存储；本地支付、访客身份与文件存储均保留后续替换边界。模拟支付不会产生真实扣款，不能用于商业收款。

## 2. 用户角色

- 访客/顾客：浏览商品、DIY 排珠、确认报价、保存方案、填写收货信息、创建和查看本人订单、模拟支付或取消待支付订单。
- 管理员：维护商品、素材、DIY 规则、工艺费和绳材；查看订单与生产 BOM；按顺序开始制作、发货和完成订单。
- 系统：校验 SKU、尺寸、价格和库存，生成权威报价与订单快照，执行库存预占/确认/释放，约束支付和履约状态机。

## 3. 已实现功能范围

### 3.1 商品目录与素材

- 管理分类、散珠 SKU、套餐、有序套餐明细和封面。
- 公共目录仅返回已上架数据，不暴露成本价。
- 支持关键字、分类、状态和分页查询。
- 商品图片限制为 PNG、JPEG、WebP，默认最大 5 MiB。
- 套餐按 SKU 与数量保存，进入 DIY 时前端临时展开为有序序列。
- 素材当前保存在本地目录，业务只依赖可替换的 `FileStorage`。

### 3.2 DIY 设计、计价与方案

- 小程序支持从空白、单颗 SKU、套餐和已保存方案进入编辑器。
- 设计状态只保存有序 SKU 数组，不为每颗珠子创建业务 ID。
- 前端支持添加、删除、替换、拖动排序、同 SKU 数量增减、撤销和重做。
- 本地预估仅用于即时反馈；最终报价由后端读取当前 SKU、DIY 规则、工艺费和绳材配置计算。
- 后端校验下架/不存在 SKU、最大珠数、腕围、尺寸偏差和绳材可用性。
- 方案支持新建、读取、更新、复制、软删除、乐观锁和预览图；跨访客访问返回 404。
- 方案保存有序 SKU 数组和报价快照；读取时重新评估报价是否过期。

### 3.3 库存与订单

- 每个散珠 SKU 保存可用、预占和已售数量，并记录库存流水。
- 创建订单必须基于当前顾客拥有的有效方案；服务端重新权威计价，不信任小程序金额。
- 订单保存方案顺序快照、按 SKU 聚合的 BOM、单价快照、总价和收货信息。
- 下单把 `available` 转为 `reserved`；库存不足返回 `INVENTORY_INSUFFICIENT` 且整个订单事务回滚。
- 待支付订单取消把 `reserved` 退回 `available`。
- 顾客只能列出和读取本人订单。

### 3.4 模拟支付与履约

- `MOCK` 支付把订单从 `PENDING_PAYMENT` 切换为 `PAID`，库存从 `reserved` 转为 `sold`。
- 重复模拟支付幂等，不重复扣库存、不重复写支付记录和履约任务。
- 支付成功后生成包含订单 SKU 数量的制作任务。
- 后台状态机严格为 `PAID → IN_PRODUCTION → SHIPPED → COMPLETED`，不能跳步。
- 发货保存模拟物流公司和运单号；小程序可查看订单最新状态。

### 3.5 三端界面

- 管理后台包含登录、商品目录、DIY 配置、订单与履约工作区。
- 小程序包含首页、目录、详情、DIY 编辑器、我的方案、确认订单、我的订单和订单详情。
- 订单详情明确标注模拟支付，不调用微信支付。

## 4. 尚未实现范围

- 未接微信授权；当前使用本地安装 UUID + 顾客 JWT，换设备或清缓存后不能自动找回。
- 未接真实对象存储；当前使用本地 `FileStorage`。
- 未接微信支付、退款、优惠券、发票、售后和真实物流查询。
- 未实现预算、色系、材质和场景规则推荐。
- 未实现库存后台调整、低库存告警和待支付订单超时自动取消。

## 5. 非功能需求

- JDK 17、Spring Boot 3、MySQL 8、Vue 3、原生微信小程序。
- 金额使用 `decimal`/`BigDecimal`；前端金额不作为报价权威。
- 数据库结构只通过 Flyway 演进。
- 管理接口使用管理员 JWT；小程序业务接口使用顾客 JWT，二者不能互换。
- 库存、订单、支付和履约写操作在数据库事务内完成，关键行使用行锁和前置状态条件。
- 统一响应含 `code`、`message`、`data`、`traceId`、`timestamp`。
- 关键流程提供 JUnit/Testcontainers、Vitest/Jest、TypeScript 检查和真实 HTTP 冒烟。
- Java 公共类型和关键规则使用中文 Javadoc；TypeScript 公共逻辑说明状态与边界。

## 6. 当前验收结果

### 本地交易闭环 V1

- 管理后台可维护商品、DIY 规则并处理订单履约。
- 小程序可浏览商品、完成 DIY、保存方案、填写地址、下单、模拟支付/取消并查看状态。
- 下单重新使用后端权威报价；库存不足不能创建订单。
- 下单预占、支付确认、取消释放均有库存余额和流水记录。
- 模拟支付幂等；订单和履约状态不能跳步。
- 方案和订单均按顾客身份隔离。
- `scripts/catalog-smoke.sh`、`scripts/diy-smoke.sh`、`scripts/order-smoke.sh` 已通过真实 HTTP 验证。

### 完整规划范围

当前本地交易产品可用于演示和非真实收款场景。完成规则推荐后可覆盖已规划的业务模块；完成微信授权、微信支付、对象存储、退款售后和生产运维清单后，才具备商业上线评估条件。
