## 后端安全与业务逻辑

修复现存符号链接导致文件读写越界、并发突破方案数量上限、多个默认地址、优惠券查询覆盖核销状态、取消后核销时间未清除、头像不能清空、集合 null 元素绕过验证，以及超量 Excel 在报错前已部分导入。

升级主要后端依赖，并新增 `prod`/`production` 早期启动保护：当前仍使用访客身份与模拟支付，生产 profile 会在数据源及应用服务初始化前拒绝启动，默认本地演示保留。

根因、失败回归和剩余边界见 [后端审查记录](../../backend-security-review-2026-09-12.md)。该记录明确说明本次未完成全依赖 SCA，Spring Boot 3.5 已结束开源支持；真实微信身份/支付、完整限流与超时关单等仍未实现，不能把这次修复作为真实交易上线验收。
