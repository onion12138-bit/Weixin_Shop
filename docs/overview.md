# 项目与文档总览

最后更新：2026-07-04

## 1. 项目目标

本项目最终交付一个可实际使用的 DIY 手串电商产品，包括 Spring Boot 后端、Vue 3
管理后台和原生微信小程序。首个可用版本使用本地图片存储、后台本地管理员账号和模拟支付；
接口边界保留后续替换微信登录、微信支付、对象存储和智能推荐的能力。

## 3. 当前可演示链路

1. Flyway 自动创建商品和素材表，并写入稳定的演示商品。
2. 管理员登录管理后台，维护分类、散珠、套餐、有序明细、封面和上下架状态。
3. 小程序读取已上架分类、散珠和套餐，完成搜索、分页与详情浏览。
4. 下架商品不会出现在公共目录；成本价不会暴露给小程序。
