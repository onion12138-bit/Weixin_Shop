# 项目与文档总览

最后更新：2026-10-23

## 1. 项目目标

本项目交付一个可实际使用的 DIY 手串电商产品，包括 Spring Boot 后端、Vue 3 管理后台和原生微信小程序。当前版本已经覆盖商品维护、商品浏览、AI 多套材质推荐、DIY 排珠、权威报价、方案保存、顾客地址/优惠券、可靠结算、库存预占与释放、订单、模拟支付和制作发货。

首个可用版本仍不接入真实支付、微信授权和对象存储；接口边界保留后续替换微信登录、微信支付、对象存储的能力。

## 3. 当前可演示链路

1. Flyway 自动创建商品、素材、访客身份、DIY 配置和方案表，并写入稳定演示数据。
2. 管理员登录管理后台，维护分类、散珠、套餐、封面、上下架和 DIY 规则。
3. 小程序读取已上架分类、散珠和套餐，完成搜索、分页与详情浏览。
4. 顾客从单颗、套餐、空白或 AI 推荐入口进入 DIY 编辑器，调整腕围、松紧、绳材和 SKU 顺序，支持指定替换及撤销/重做。
5. 小程序展示本地预估价，确认报价时由后端生成权威价格。
6. 顾客保存方案，后续在“我的方案”恢复原始 SKU 顺序，也可复制或删除。
7. 顾客选择本单地址和券，核对服务端报价；设计版本或价格变化需再次确认。提交前保存请求令牌，后端同键防重并预占库存，弱网可找回订单。
8. 顾客执行明确标注的模拟支付，或在支付前取消；逾期由服务端关闭，释放库存与可恢复的券。
9. 支付后进入制作，管理员查看 SKU 汇总 BOM，完成制作、填写物流公司/单号，再完成订单；顾客也可确认收货。提醒操作只记日志，尚不发送消息。

## 4. 明确限制

- 未接微信授权；访客身份只绑定本地安装 UUID。
- 未接真实对象存储；图片和预览图当前使用本地目录。
- AI 已支持多套材质灵感，未实现预算/数量/排列自动规划或本地规则推荐。
- 小程序访客方案只能在同一安装身份下访问。
- 当前支付仅为 `MOCK`，不能完成真实交易收款；也未实现退款、售后和真实物流查询。

本轮实现范围为 R01/R02/R03/R04/R06-A/R20。R05 位置编号制作单、质检/返工/打印，真实消息发送、真实支付与分享营销仍留在后续需求池。当前履约任务是 SKU 汇总 BOM 和状态流转，不代表已有完整制造工单。
