## 状态与完成度口径

- `已完成`：验收标准已满足，自动化验证通过。
- `进行中`：已有实现，但阶段验收尚未全部满足。
- `待开发`：已确认范围，尚未开始实现。
- `受阻`：存在无法在当前权限或环境内解决的明确阻塞。
- 完成度只使用 `0%`、`25%`、`50%`、`75%`、`100%` 五档。

## 维护规则

1. 每完成一个可验收阶段，同步更新模块主表和阶段记录。
2. 验证结果只能记录实际执行结果，不记录预测。
3. 整体进度必须根据主表完成度重新计算。
4. 主表只保留当前状态，历史状态只进入阶段记录。
5. 需求范围变化时，先更新 `requirements.md`，再调整模块和完成度。
