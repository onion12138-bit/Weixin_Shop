# DIY 串珠编辑页视觉改版设计

## 目标

在不改变后端接口、报价规则、方案数据结构、Canvas 渲染、拖动排序和保存流程的前提下，按照用户提供的四张参考图重排原生微信小程序 DIY 串珠页面，并将全小程序页面背景统一为首页使用的浅丝绸粉纯色 `#fff8fa`。

## 范围

### 本次包含

- 调整 DIY 编辑页的尺寸信息、选中珠子操作、预览折叠、珠子库布局、喜欢状态和喜欢筛选。
- 喜欢状态使用小程序本地存储，不新增后端接口或数据库表。
- 将小程序全局窗口背景、导航栏背景和各页面根容器背景统一为 `#fff8fa`。
- 保留现有商品图片、Canvas 手串预览和 Remix Icon 图标体系。
- 为新增前端状态和行为补充 Jest 测试，并在微信开发者工具中执行视觉验收。

### 本次不包含

- 不修改 Java 后端、数据库迁移、管理后台或 API 文档。
- 不修改报价、腕围、松紧、绳材、方案保存和订单业务规则。
- 不提供跨设备喜欢同步；清理缓存或卸载小程序会丢失本地喜欢记录。
- 不新增页面或路由。

## 设计方案

采用现有页面局部重排。`pages/diy/editor` 继续持有全部编辑状态和现有业务调用，只新增三个纯前端状态：预览是否展开、喜欢的珠子 ID 集合、是否只看喜欢。这样可以保留成熟的 Canvas 和数据派生逻辑，同时让新增交互可独立测试。

## 页面结构

### 顶部配置

保留腕围、贴合度和绳材三个 picker。按钮沿用当前数据和事件，只调整为首页同系的白色半透明胶囊卡片，页面底色改为 `#fff8fa`。

### 手串预览

- 默认展开，右上角按钮文案为“收起预览”。
- 展开态保留完整 Canvas、撤销和重做操作。
- 收起后切换为横向窄卡：左侧显示缩小后的手串预览，右侧显示颗数和尺寸信息，右上角按钮文案改为“展开预览”。
- 折叠只改变前端布局和 Canvas 容器尺寸，不重建方案状态；切换后重新测量并绘制 Canvas。
- 尺寸信息左对齐、分两行显示：第一行“目标 N mm”，第二行“当前 N mm”。
- 删除“偏短，请增加珠子或调整腕围”“尺寸合适”等建议文案，不再在预览区展示 `sizeText`。

### 选中珠子操作

- 仅在选中某颗珠子后显示。
- 删除“第 N 颗”“替换”“删除”等可见控件。
- 只保留减号和加号按钮，并整体靠右排列。
- 两个按钮继续复用现有 `decreaseSelectedSku` 和 `increaseSelectedSku`，因此数量调整、历史记录、报价和草稿逻辑不变。

### 珠子库

- 分类标签保持横向滚动。
- 搜索行包含：关键词输入框、“喜欢”筛选按钮和“搜索”按钮。
- 喜欢筛选按钮提供空心/实心爱心状态；开启时只展示已喜欢且符合当前分类与关键词的珠子。
- 珠子展示从横向托盘改为三列向下展开网格。
- 每张卡片显示珠子图片、名称、直径和价格；右上角显示爱心按钮。
- 点击卡片主体继续调用 `addCatalogBead`；点击爱心使用 `catchtap`，只切换喜欢状态，不触发加珠。
- 当前已选择或刚加入的珠子保持现有 Canvas 选中反馈；珠子库卡片不新增后端选择状态。

## 喜欢状态

- 本地存储键使用 `diy_favorite_bead_ids`。
- 存储值为去重后的正整数 SKU ID 数组。
- 页面加载时读取并校验本地值；格式错误时按空数组处理，不阻塞编辑器加载。
- 点击爱心后立即更新页面状态和 `wx.setStorageSync`。
- 喜欢筛选基于当前页面可用目录数据计算；如果没有匹配项，显示“还没有喜欢的珠子”空状态。
- 搜索或切换分类后继续保留喜欢筛选开关。

## 数据和行为边界

- 后端 `listBeads` 仍负责分类与关键词查询；页面收到数据后合并到当前目录。
- 喜欢筛选只在前端对当前已加载目录过滤，不向 API 增加参数。
- 为避免筛选后丢失目录项，页面保留完整 `catalog`，另派生 `visibleCatalog` 供 WXML 渲染。
- `toggleFavorite`、`toggleFavoriteFilter` 和目录查询完成后统一调用一个目录派生方法，保证三种筛选条件可组合。
- 预览展开状态不写入草稿或数据库；每次打开页面默认展开。

## 全局视觉

- `app.json` 的 `navigationBarBackgroundColor` 和 `backgroundColor` 改为 `#fff8fa`。
- `app.wxss` 的 `page` 背景改为 `#fff8fa`。
- 首页、推荐、目录、商品详情、DIY、方案、订单确认、订单列表和订单详情的根容器背景统一为 `#fff8fa`。
- 内容卡片使用白色或约 90% 不透明白色，强调色继续使用深紫 `#754657` 和首页粉色系；不把丝绸图片平铺到页面，避免影响文字可读性和包体积。

## 错误处理

- 本地喜欢记录读取或写入失败时不影响串珠、报价或保存流程；写入失败显示轻提示“喜欢记录未保存”。
- 目录接口失败继续使用现有错误提示，不清空已加载目录或本地喜欢状态。
- 折叠切换后的 Canvas 重绘沿用现有延迟合并机制，避免短时间重复绘制。

## 测试与验收

- Jest 验证：预览展开/收起文案和状态、喜欢读取校验、爱心切换与持久化、喜欢筛选、分类/关键词组合筛选、加减按钮继续更新序列。
- 类型检查使用现有 `tsconfig.runtime.json`。
- 微信开发者工具验证：展开态、收起态、三列珠子网格、喜欢选中态、喜欢筛选空状态和全局粉色背景。
- 将四张用户参考图与最终 DIY 页面截图放入同一对比证据，修复所有 P0/P1/P2 视觉问题后更新项目根目录 `design-qa.md` 为 `final result: passed`。

## 成功标准

- 后端和数据库零改动。
- 原有串珠、拖动、撤销、重做、报价、保存草稿和方案入口继续工作。
- 用户要求删除的建议、替换、删除和颗数序号控件不再显示。
- 预览可以稳定展开和收起，珠子库可以向下浏览、收藏和筛选。
- 小程序所有页面的可见根背景统一为 `#fff8fa`。
