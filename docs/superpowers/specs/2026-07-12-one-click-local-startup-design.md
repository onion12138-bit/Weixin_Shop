# 管理后台一键启动设计

日期：2026-07-12

## 1. 目标

在 macOS 上提供项目根目录中的可双击 `.command` 文件。用户双击一次后，无需手动输入终端命令，即可启动 MySQL、Redis、Spring Boot 后端和 Vue 管理后台，并自动打开 `http://localhost:5173`。

本功能只服务本地开发，不改变生产部署方式，也不修改微信小程序配置。

## 2. 方案选择

采用“根目录双击入口 + 可测试启动脚本”的方案：

- 根目录 `.command` 文件只负责定位项目目录并调用启动脚本，方便 Finder 双击；
- `scripts/start-local.sh` 负责环境检查、服务启动、就绪等待、日志和浏览器打开；
- 不使用 AppleScript 创建多个终端窗口，减少系统权限弹窗；
- 后端和管理后台以后台进程运行，日志和 PID 写入 Git 忽略的本地运行目录。

没有采用仅启动 Vue 的方案，因为后台登录和业务操作依赖 Spring Boot、MySQL 和 Redis。没有把全部逻辑塞进 `.command` 文件，以便单独测试启动逻辑。

## 3. 启动流程

1. 根据脚本自身位置解析项目根目录，不依赖用户当前目录。
2. 加载 `scripts/project-env.sh`；如果存在 `.env`，沿用其中配置。
3. 检查 Docker、Java 17、Maven、Node.js 和 pnpm。
4. 执行 `docker compose up -d`，并确认 MySQL、Redis 容器启动。
5. 检查后端健康接口：
   - 若配置端口已经是本项目后端，则直接复用；
   - 若端口被其他程序占用且健康接口不匹配，则为本次后台会话选择空闲备用端口，不修改 `.env`；
   - 将 Vue 的 `VITE_API_BASE_URL` 同步指向本次实际后端端口。
6. 后台启动 Spring Boot，并等待健康接口成功或输出明确错误。
7. 若 5173 已经是本项目 Vue 服务则复用；否则端口冲突时停止并提示，不静默改后台地址。
8. 后台启动 Vue，等待首页可访问。
9. 调用 macOS `open` 打开 `http://localhost:5173`，在终端显示地址、默认账号、日志位置和进程状态。

## 4. 文件与运行数据

- 新增根目录 `启动管理后台.command`。
- 新增 `scripts/start-local.sh`。
- 本地日志和 PID 存入 `.local-run/`。
- `.gitignore` 增加 `.local-run/`，避免运行产物进入版本控制。
- 不修改或提交 `miniprogram/project.config.json`、`Pic/` 及其他现有用户改动。

## 5. 错误处理

- Docker Desktop 未运行、依赖缺失、容器启动失败、后端失败或 Vue 失败时，脚本以非零状态退出并保留终端窗口供用户查看。
- 等待服务设置有限超时，避免永久卡住。
- 重复双击不会重复启动已经健康的项目服务。
- 启动失败时显示对应日志文件路径，不删除旧日志。
- 8080 被 Jenkins 等其他进程占用时不结束该进程，也不修改系统配置。

## 6. 验证

- 对两个 Shell 文件执行语法检查。
- 用隔离的命令替身验证项目路径、启动顺序、端口复用/冲突分支和失败退出。
- 在本机实际执行入口，确认 Docker 服务、后端健康接口、Vue 首页和自动打开地址。
- 验证 Git 状态，确保原有 `miniprogram/project.config.json` 和 `Pic/` 不受影响。

## 7. 验收标准

- Finder 双击 `启动管理后台.command` 后，无需输入命令即可启动完整管理后台依赖。
- 后台最终可通过 `http://localhost:5173` 访问。
- 8080 端口存在 Jenkins 时不会终止或覆盖 Jenkins。
- 失败信息可理解，日志可定位，重复启动不会产生重复服务。
