# 单珠阴影透明度减半设计

日期：2026-08-11
状态：已确认

## 目标

将 DIY 手串预览中的单珠阴影透明度从 `0.20` 调整为 `0.10`，使阴影视觉重量减少一半。阴影的半径、偏移、颜色、珠子尺寸、素材和其他 2.5D 参数保持不变。

## 实现决策

采用配置层调整，不在小程序渲染器中额外乘系数。这样管理后台显示的透明度与小程序实际绘制值保持一致。

具体变更：

1. 新增 Flyway 数据迁移，将 `diy_visual_config.id = 1` 的 `bead_shadow_opacity` 设置为 `0.100`，并递增 `config_version`，确保已经运行过旧迁移的数据库也能获得新值。
2. 将管理后台 DIY 设置页的本地初始值同步为 `0.10`，避免配置接口返回前短暂保留旧默认值。
3. 不修改已经发布的旧迁移文件，避免 Flyway 校验和变化。
4. 不修改 `drawBeadShadow` 的几何参数；渲染器继续直接使用后端返回的 `beadShadowOpacity`。

## 数据流

数据库中的 `0.100` 经 DIY 公共配置接口返回给小程序。小程序构建渲染计划后，将该值直接传给 Canvas 阴影绘制函数。因此已有方案和新方案都会使用减半后的全局阴影透明度，无须重做珠子素材。

## 测试与验收

1. 迁移测试应证明最终数据库中的 `bead_shadow_opacity` 为 `0.100`。
2. 管理后台测试应证明本地初始配置为 `0.10`，并仍可加载和保存服务端配置。
3. 小程序渲染测试继续证明渲染器原样使用配置透明度，避免加入隐藏倍数。
4. 聚焦测试通过后运行相关后台和小程序测试，确认未影响其他 DIY 配置与 Canvas 绘制行为。

验收标准：默认单珠阴影透明度由 `0.20` 变为 `0.10`，其他视觉参数完全不变。
