# 项目性能、安全和中文注释审查

审查日期：2026-10-23。范围包括微信小程序、Vue 管理后台、Java 后端、依赖锁文件、启动脚本与本地部署配置。
本轮保留了此前未提交的防重复点击、DIY 异步预览和开发工具配置修改。未修改运行数据库、用户缓存或现有密钥，未提交、推送或发布。

## 结论

存在可修复的安全、并发和性能问题，已完成下述修改并通过自动化验证。当前仍是本地演示系统，不能据此认定满足真实交易上线要求。
检查方式包括源码审阅、静态检索、官方依赖漏洞库核查、并发及生命周期回归、独立 MySQL 集成测试；不包含真机耗时采样、压力测试或完整渗透测试。

## 本轮修复

| 范围 | 原问题及影响 | 修复与证据 |
| --- | --- | --- |
| 本地部署 | 后端与 MySQL/Redis 默认向所有网卡开放，演示凭据及未鉴权 Redis 增加局域网暴露风险 | 默认绑定 127.0.0.1；Compose 渲染结果确认两项端口均只发布到本机；真机联调需显式开放后端 |
| 启动脚本 | 将实际管理员密码写入终端输出 | 移除密码打印，使用独立测试密码验证完整启动输出不包含该值 |
| 小程序身份 | 调用了不存在的同步随机数接口，实际降级为 Math.random 生成可恢复身份的安装标识 | 改用微信 UserCryptoManager 的异步密码学随机数；不支持时明确失败；保留已有安装标识，首次并发请求共用生成过程 |
| 小程序会话 | 迟到的 401 可删除其他请求刚刷新的令牌 | 刷新前比较失败请求使用的令牌，复用新令牌，并保持最多一次重试 |
| 小程序请求 | 全量珠库一次并发请求全部剩余页，挤占带宽与请求名额 | 每批最多 3 页，保留顺序和去重结果 |
| 小程序生命周期 | 退出编辑/商品/结算页面后，旧请求仍可回写、弹窗或强制跳转；离线预热有未捕获异常 | 补齐退出检查、清理订阅及预热失败捕获；创建成功的订单保持可在订单列表查询 |
| 后台导出 | 收件人、商品名等用户输入可能在 CSV 打开时被当作电子表格公式 | 统一保护公式前缀、控制字符及引号；新增 CSV 回归 |
| 后台编辑 | 关闭商品表单再编辑另一商品时，旧封面上传结果可能写入新表单 | 上传代次校验、关闭时失效、保存期间防止切换 |
| 后台提交 | 部分业务只禁用按钮，没有函数级互斥；客户查询存在过期响应覆盖 | 补充保存、库存、导入、履约、登录等提交锁和响应代次检查 |
| 后台性能 | 批量履约没有并发上限；清除按钮在每次滚动中重复交错读写布局 | 批量最多 4 个并发，卸载后不再启动剩余业务请求；布局测量按帧合并、先读后写并清理监听 |
| 后台安全加固 | 前端预填演示密码；资源 URL 缺少协议限制；管理数据可能进入 HTTP 缓存 | 移除预填凭据，仅接受 HTTP/HTTPS 资源地址，管理请求和下载使用 no-store |
| 后端订单 | 小程序每条订单另查明细和物流；后台每条订单重复读取多张关联表 | 小程序由 1+2N 次查询降为非空列表固定 3 次；后台按当前分页批量读取；新增关联正确性及列表/详情一致性回归 |
| 后端 AI | 慢模型请求没有应用级并发上限，同一顾客可重复并发消耗资源 | 单进程默认最多 4 个请求（可配置 1–32），同顾客并发互斥，成功和异常均归还名额 |
| 后端 AI 日志 | 列表读取不需要的大段提示词、候选集和响应 JSON | 列表只取摘要，大字段留到详情读取 |
| 开发环境 | 环境检查允许 Node 20/23 等不兼容前端工具链的版本 | 与 engines 对齐，检查 Node 22.13+ 的 22.x 或 24+；验证五组版本接受/拒绝结果 |

代码已有的 JWT 角色隔离、资源所有权校验、库存事务和锁顺序、文件目录穿越/符号链接防护、AI 上游域名白名单仍保留。
新增忽略本地上传目录和包管理缓存，降低后续误提交风险；历史上已经跟踪的文件不会因忽略规则自动从仓库删除。

## 依赖核查

证据摘要保存在 [dependency-audit.json](qa/2026-10-23/dependency-audit.json)。npm 使用官方 registry，后端按 Maven 实际解析出的 83 个运行依赖查询 OSV；此处不包含全部 Maven 构建插件、测试依赖和容器镜像扫描。

| 项目 | 结果 |
| --- | --- |
| 管理后台 | 12 条降至 0 条：Vue 3.5.42、Vite 6.4.4、Vitest 4.1.12，并更新相关间接依赖 |
| 小程序工具链 | 8 条降至 2 条：brace-expansion 已更新；剩余 braces（高）和 sprintf-js（中）均来自测试工具链 |
| 后端 | Tomcat 10.1.61、Jackson BOM 2.21.7、Log4j2 2.25.5；复查 83 个运行依赖剩 Spring MVC 的 2 条条件性告警 |

小程序剩余告警的公告修复版本为 braces 3.0.4、sprintf-js 1.1.4，但本轮直接查询官方 registry 时，最新可发布安装版本仍分别为 3.0.3 和 1.1.3。
未保留指向不存在版本的覆盖配置，也未忽略告警；当前锁文件可冻结离线安装。两项不属于微信小程序运行时代码，但开发环境不应把不可信输入交给测试工具链处理。

Spring MVC 6.2.19 剩余 [CVE-2026-47890](https://spring.io/security/cve-2026-47890/) 与 [CVE-2026-47884](https://spring.io/security/cve-2026-47884/)。
前者要求 SSE 传输视图片段，后者要求 XsltView 视图渲染条件；当前源码未使用这些功能，因此未确认存在对应可达利用路径。
6.2.20 修复版仅商业可用，长期需要迁移到受支持框架；不能将“未使用触发功能”描述为组件漏洞清零。

更新依据还包括 [Tomcat 官方公告](https://tomcat.apache.org/security-10.html)、[Jackson core 公告](https://github.com/FasterXML/jackson-core/security/advisories/GHSA-7hhh-6rmp-j9qf)、[Jackson databind 公告](https://github.com/FasterXML/jackson-databind/security/advisories/GHSA-cxp5-3px4-pw24)和 [Log4j 修复记录](https://github.com/apache/logging-log4j2/pull/4163)。

## 剩余边界与下一步

1. 身份仍是安装 UUID，支付仍为 MOCK；历史身份标识没有被强制更换。生产 profile 已被禁止启动，演示配置不能直接用于公网真实交易。
2. 仍需登录/建号/上传的频率限制、存储配额、图片实际解码校验、跨实例 AI 次数与费用控制。当前 AI 并发保护不等同于费用配额。
3. 管理后台客户列表和小程序订单列表仍全量读取；套餐编辑选珠只取前 100 条，完整珠库仍会加载全量数据。数据增长后需增加服务端分页及按 ID 查询接口。
4. 管理员令牌仍使用 localStorage；AI 日志保存生日、愿望等业务内容，尚需保留期限和清理策略。
5. 保留上述 4 条依赖告警及受支持框架迁移计划，未隐藏或豁免扫描结果。

本轮变更需要安装更新后的锁定依赖、重启后端并重新编译小程序后生效；数据库/Redis 的绑定变化在下次重建对应容器时生效。
